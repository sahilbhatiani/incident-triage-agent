# Postmortem: Checkout failures after payments v2.18 release

## Summary
Checkout errors reached 9% for 22 minutes after payments v2.18.0 was rolled out. A null currency field in a refactored handler threw NullPointerException on every charge request.

## Timeline
- 14:02 Deployment payments@v2.18.0 rolled out.
- 14:03 payments error_rate stepped from 0.1% to 11%.
- 14:04 gateway 5xx alert fired; on-call initially suspected the gateway load balancer.
- 14:19 Deploy log correlated with the error onset; rollback started.

## Lessons
- Always check the deploy log of the service whose errors began first, not the alerting service.
