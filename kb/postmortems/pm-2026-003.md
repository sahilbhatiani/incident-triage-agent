# Postmortem: Inventory regression masked by a concurrent payments deploy

## Summary
Two services deployed within four minutes. inventory@v2.31.0 introduced an exception in the SKU handler; payments@v1.72.0 was harmless. The first responder rolled back payments, which did not help.

## Lessons
- With concurrent deploys, roll back the one whose error_rate moved, not the one deployed last.
